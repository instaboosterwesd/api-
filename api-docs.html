ORIGINAL SITE KAISE KAAM KARTI HAI (repo se samjha)
-----------------------------------------------------
1) LOGIN  : Website par login Google Sign-in (Firebase Auth) se hota hai.
            Login ke baad Profile -> API settings me ek private key milti hai
            jo "tg_" se start hoti hai.
2) VERIFY : Har API request par key check hoti hai:
            key ka SHA-256 hash  ->  Firebase "apiKeys/<hash>"  -> user uid
            user banned/inactive ho to 403.
3) BUY    : Wallet se paisa kat-ta hai -> provider (xyzcheats reseller API)
            se license key aati hai -> order save hota hai. Fail hone par
            wallet refund ho jata hai.

Yeh "My API" usi main API par same tarah request bhejti hai aur JSON me
jawab deti hai.

BASE URL
-----------------------------------------------------
https://YOUR-DOMAIN/api

AUTHENTICATION
-----------------------------------------------------
Apni tg_ key in me se kisi ek tarah bhejo:
  Header:  x-api-key: tg_xxxxxxxx
  Header:  Authorization: Bearer tg_xxxxxxxx
  Body  :  "api_key": "tg_xxxxxxxx"   (sirf POST)

-----------------------------------------------------
1. BALANCE         GET /api?action=balance
-----------------------------------------------------
curl -H "x-api-key: tg_xxx" "https://YOUR-DOMAIN/api?action=balance"

Response:
{ "success": true, "balance": 500, "currency": "INR" }

-----------------------------------------------------
2. ALL PRODUCTS    GET /api?action=products
-----------------------------------------------------
curl -H "x-api-key: tg_xxx" "https://YOUR-DOMAIN/api?action=products"

Response:
{ "success": true, "account_type": "user", "count": 2,
  "products": [ { "pid": "133", "purchase_pid": "133", "name": "...",
                  "durations": [ { "duration": "1 Day", "price": 99 } ],
                  "get_file_link": "...", "feedback_link": "..." } ] }

-----------------------------------------------------
3. ONE PRODUCT     GET /api?action=product&pid=133
-----------------------------------------------------
curl -H "x-api-key: tg_xxx" "https://YOUR-DOMAIN/api?action=product&pid=133"

Response:
{ "success": true, "account_type": "user", "product": { ... } }

-----------------------------------------------------
4. BUY KEY         POST /api?action=buy
-----------------------------------------------------
Body (JSON):
  product_id   (required)  product PID
  duration     (required)  jaise "1 Day", "7 Days"
  android_id   (optional)  Bala device-bound products ke liye required

curl -X POST "https://YOUR-DOMAIN/api?action=buy" \
  -H "x-api-key: tg_xxx" -H "Content-Type: application/json" \
  -d '{"product_id":"133","duration":"1 Day"}'

Response (201):
{ "success": true, "message": "Order placed successfully.",
  "order": { "id": "lk_api_...", "product": "...", "duration": "1 Day",
             "price": 99, "key": "XXXX-XXXX", "status": "active",
             "get_file_link": "...", "feedback_link": "...",
             "created_at": 1760000000000 } }

-----------------------------------------------------
ERROR FORMAT (hamesha JSON)
-----------------------------------------------------
{ "success": false, "error": { "code": "CODE", "message": "..." } }

 401  API_KEY_MISSING / invalid key
 403  account banned
 400  REQUIRED_FIELDS_MISSING, DURATION_NOT_FOUND, ANDROID_ID_REQUIRED,
      UNKNOWN_ACTION, PRICE_NOT_AVAILABLE
 402  INSUFFICIENT_BALANCE
 404  PRODUCT_NOT_FOUND
 405  METHOD_NOT_ALLOWED
 502  PROVIDER_PURCHASE_FAILED (wallet refund ho jata hai)
 504  UPSTREAM_UNREACHABLE

-----------------------------------------------------
SETUP / HOSTING
-----------------------------------------------------
Environment variable:
  UPSTREAM_URL = https://<main-site>/api/public-api

Vercel : folder upload karo, UPSTREAM_URL set karo, deploy.
VPS    : UPSTREAM_URL=... node server.js   (port 3000)
